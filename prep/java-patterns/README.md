# Java coding patterns — quick lookup

Barclays-style Easy–Medium shapes. Open a file, copy the skeleton, adapt.

| File | Patterns |
|------|----------|
| `SlidingWindow.java` | longest with K distinct, min window substring, max sum window of size K |
| `TwoPointers.java` | pair sum (sorted), container with most water, remove duplicates, reverse |
| `Strings.java` | anagrams, first unique char, valid parentheses, compress, palindrome |
| `HashMapPatterns.java` | two sum, subarray sum = K, group anagrams, frequency |
| `PrefixSum.java` | range sum, equal 0/1 subarray, contiguous array |
| `Intervals.java` | merge intervals, activity selection / max meetings |
| `HeapTopK.java` | kth largest, top-K frequent |
| `Greedy.java` | buy-1-get-K-free min/max cost |

Run any class: `javac prep/java-patterns/*.java && java -cp prep/java-patterns SlidingWindow`
